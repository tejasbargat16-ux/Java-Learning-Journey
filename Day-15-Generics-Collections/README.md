## Mini-Project

The Generic Repository provides reusable operations for storing, retrieving, searching, and removing objects of different types.

## Learning Outcomes

After Day 15, I can:

- Write generic classes and methods
- Use type parameters to improve type safety
- Apply bounded generics
- Sort collections and custom objects
- Use `Comparable` and `Comparator`
- Build reusable data-management components

## Important Note

The repository stores data in memory only. It does not provide database persistence.
