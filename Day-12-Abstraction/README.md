# Java Day 12 — Abstraction

## Topics Covered

- Abstraction in Java
- Abstract classes
- Abstract methods
- Concrete methods
- Constructors in abstract classes
- Interfaces
- `extends` and `implements`
- Runtime polymorphism
- Practical OOP applications

## Learning Outcomes

After Day 12, I can:

- Explain abstraction and why it is useful
- Create abstract classes and methods
- Implement interfaces
- Override abstract methods
- Use constructors in abstract classes
- Apply abstraction with runtime polymorphism
- Build small Java OOP applications

## Mini-Project

The Payment System demonstrates how different payment methods can follow a common abstract contract while providing different implementations.

This is a learning simulation and does not process real payments.
