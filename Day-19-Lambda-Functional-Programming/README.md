## 🧠 Key Learnings

- Lambda expressions reduce unnecessary code.
- Functional interfaces provide the foundation for lambdas.
- Predicate tests conditions.
- Consumer processes input without returning a value.
- Supplier provides values.
- Function transforms values.
- Method references make suitable lambdas shorter.
- Streams provide a declarative way to process collections.
- Intermediate stream operations are lazy and execute when a terminal operation is invoked.
