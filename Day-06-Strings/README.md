# ☕ Day 06 — Strings

## 🎯 Topics Covered
- String fundamentals and immutability
- String length using `.length()`
- Character access using `.charAt()`
- Case conversion with `.toUpperCase()` and `.toLowerCase()`
- String comparison (`.equals()` and `.equalsIgnoreCase()`)
- Searching with `.contains()`, `.indexOf()`
- Extracting text using `.substring()`
- Reversing strings and checking palindromes
- Counting vowels, consonants, and words
- Whitespace manipulation with `.replace()` and `.trim()`
- Character frequency counting

## 🧠 Key Learning
Strings are objects in Java and are immutable (cannot be changed once created). I practiced key built-in methods including `.length()`, `.charAt()`, `.equals()`, `.equalsIgnoreCase()`, `.contains()`, `.substring()`, `.toUpperCase()`, `.toLowerCase()`, and `.replace()`. Combining string methods with loops allows solving practical challenges like palindromes, word counts, and character frequency analysis.
