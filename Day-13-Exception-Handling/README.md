Key Concepts

- "try": Wraps code that may throw an exception.
- "catch": Handles a matching exception.
- "finally": Provides a cleanup section that normally executes whether an exception occurs or not.
- "throw": Throws an exception explicitly.
- "throws": Declares exceptions a method may pass to its caller.
