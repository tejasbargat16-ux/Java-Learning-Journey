# ☕ Day 01 — Basics

## 🎯 Topics Covered
- Basic structure of a Java program
- Entry point and how the `main()` method works
- Printing output using `System.out.println()` and `System.out.print()`
- Variables and data types (`String`, `int`, `double`, `char`, `boolean`)
- Basic mathematical arithmetic operations (`+`, `-`, `*`, `/`, `%`)
- Practice writing simple Java programs

## 📂 Programs
| File | Description |
|:---|:---|
| `HelloWorld.java` | Entry point program printing first Java output |
| `Variables.java` | Declaration and initialization of primitive data types |
| `BasicCalculation.java` | Basic arithmetic calculations with integers and doubles |
| `MyIntroduction.java` | Prints a formatted personal introduction |
| `StudentDetails.java` | Stores and displays student information |
| `Calculator.java` | Performs basic arithmetic operations |
| `PersonalProfile.java` | Displays a complete formatted personal profile |

## 🧠 Key Learning
Today I understood that Java programs are built around classes and methods. Execution starts from the `main()` method. I learned how variables store different types of data and how operators can be used to perform calculations.
