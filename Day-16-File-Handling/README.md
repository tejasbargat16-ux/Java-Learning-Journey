After Day 16, I can:

- Create files and directories
- Read and write text files
- Append content without overwriting
- Inspect file properties
- Use Java NIO Files and Path APIs
- Handle IOException
- Build basic file-based applications

The Notes Manager stores data locally in a text file. It does not use a database or cloud storage.
